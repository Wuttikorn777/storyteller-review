**ที่มาของปัญหาและความสำคัญ**

ในยุคปัจจุบันที่เทคโนโลยีและอินเทอร์เน็ตมีบทบาทสำคัญในชีวิตประจำวัน วงการภาพยนตร์ได้รับความนิยมมากขึ้น ส่งผลให้การรีวิวภาพยนตร์กลายเป็นส่วนสำคัญที่ช่วยให้ผู้ชมสามารถตัดสินใจเลือกชมภาพยนตร์ที่ตรงกับความสนใจของตนเอง เว็บไซต์สำหรับนักรีวิวภาพยนตร์จึงเป็นแหล่งข้อมูลสำคัญที่ช่วยให้ผู้ใช้สามารถเข้าถึงบทวิจารณ์ ข้อมูลเกี่ยวกับภาพยนตร์ และความคิดเห็นจากผู้ชมได้อย่างสะดวกสบาย โปรเจคนี้เกิดขึ้นเพื่อตอบสนองต่อความต้องการของนักรีวิวภาพยนตร์และผู้ที่สนใจติดตามบทวิจารณ์ โดยมีเป้าหมายเพื่อสร้างแพลตฟอร์มที่เปิดโอกาสให้ผู้ใช้งานสามารถแบ่งปันความคิดเห็น วิเคราะห์เนื้อหา และให้คะแนนภาพยนตร์ได้อย่างอิสระ เว็บไซต์นี้จะช่วยให้นักรีวิวสามารถเผยแพร่บทความเกี่ยวกับภาพยนตร์ รวมถึงให้ข้อมูลที่เป็นประโยชน์แก่ผู้ที่กำลังมองหาภาพยนตร์ที่เหมาะสมกับรสนิยมของตน เว็บไซต์นี้รองรับฟีเจอร์ต่าง ๆ เช่น การโพสต์รีวิวภาพยนตร์ การให้คะแนนและแสดงความคิดเห็น ระบบการจัดอันดับภาพยนตร์ยอดนิยม นอกจากนี้ยังมีการจัดหมวดหมู่ภาพยนตร์ที่ช่วยให้ผู้ใช้งานสามารถค้นหาภาพยนตร์ที่น่าสนใจได้ง่ายขึ้น ผู้ใช้งานสามารถสร้างบัญชีเพื่อเก็บบันทึกภาพยนตร์ที่เคยรีวิว แชร์บทความกับผู้อื่น และร่วมพูดคุยแลกเปลี่ยนความคิดเห็นกับชุมชนนักรีวิวภาพยนตร์ ดังนั้น โปรเจคนี้จึงเป็นการตอบสนองต่อความต้องการของผู้ที่รักการรีวิวและติดตามข่าวสารเกี่ยวกับภาพยนตร์ โดยมีเป้าหมายเพื่อสร้างแพลตฟอร์มที่สะดวก ทันสมัย และมีประสิทธิภาพในการเข้าถึงข้อมูลเกี่ยวกับภาพยนตร์ได้อย่างครบถ้วน

**วัตถุประสงค์และประโยชน์ที่คาดว่าจะได้รับ**

1.เพื่อให้ผู้ใช้สามารถค้นหาภาพยนตร์ที่เหมาะกับความสนใจของตนเอง 

2.เพื่อให้ข้อมูลและรีวิวภาพยนตร์ที่เป็นประโยชน์ 

3.เพื่อให้ผู้ชมสามารถแลกเปลี่ยนความคิดเห็นเกี่ยวกับภาพยนตร์ได้อย่างอิสระ 

4.เพื่อเพิ่มความสนุกสนานและความน่าสนใจในการชมภาพยนตร์

**ขอบเขตของโครงงาน**

1.เว็บไซต์รวมรีวิวหนังสำหรับผู้ใช้ที่อยากเห็นจากผู้ใช้จริง 

2.มีระบบแสดงความคิดเห็นเกี่ยวกับหนัง และโต้ตอบกับผู้ใช้อื่นในเว็บไซต์ได้

3.มีระบบการจัดหมวดหมู่และการค้นหา

4.มีระบบการให้คะแนนติดดาว และจัดลำดับความนิยม

5.มีระบบควบคุมเนื้อหา และความเหมาะสมตามวัย

**Functional Requirement and Non-Functional Requirement**

**Functional Requirement**

1.ระบบสามารถบันทึกและแสดงข้อมูลภาพยนตร์ เช่น ชื่อเรื่อง ปีที่ออกฉาย แนวภาพยนตร์ และผู้กำกับ 

2.ระบบสามารถรองรับการเพิ่ม แก้ไข และลบรีวิวภาพยนตร์โดยผู้ใช้งาน

3.ผู้ใช้งานมีฟังก์ชันการให้คะแนนภาพยนตร์ และแสดงคะแนนเฉลี่ยจากผู้ใช้งาน 

4.ระบบสามารถจัดหมวดหมู่ภาพยนตร์ตามประเภท แนวภาพยนตร์ และความนิยม 

5.ระบบรองรับการค้นหาภาพยนตร์ตามชื่อเรื่อง ผู้กำกับ หรือประเภทภาพยนตร์ 

6.ผู้ใช้สามารถแสดงความคิดเห็นและตอบกลับความคิดเห็นบนรีวิวภาพยนตร์

**Non-Functional Requirement**

1.ผู้ใช้ต้องการหน้าตาเว็บไซต์เข้าถึงง่าย 

2.ผู้ใช้อยากให้หน้าเว็บไม่เกิน 5 วิ 

3.ไม่อยากให้มีการเว็บล่มเนื่องจากการใช้งานมากเกินไป 

4.ต้องการให้ใช้เว็บไซต์ได้กับทุกระบบ 

5.หากมีการปรับปรุงเว็บไซต์อยากให้มีผลกระทบน้อยที่สุด

**Data structure**

Linked List 
- ใช้เก็บความคิดเห็นที่มีการเชื่อมโยงกัน เช่น ความคิดเห็นที่ตอบกลับกันในรีวิว 
- ใช้แสดงผลข้อมูลที่มีการเรียงลำดับตามลำดับเวลาของการโพสต์

Queue 
- จัดการรีวิวที่มีการเพิ่มใหม่ในระบบ เช่น การแสดงรีวิวที่ถูกเพิ่มเข้ามาล่าสุดในคิว

Trie 
- ใช้ในการค้นหาชื่อหนังอย่างรวดเร็ว

Matrix 
- ใช้จัดเก็บคะแนนการรีวิวของหนังในแต่ละหมวดหมู่ เช่น คะแนนการรีวิวแยกตามประเภทต่างๆ
